Blocco al riavvio

Su un server che si riavvia da solo lascialo spento: dopo ogni riavvio Leggio resterebbe fermo, e i tuoi agenti senza posta, finché qualcuno non entra nella console.

Cosa fa Leggio per proteggerti

API per agenti

Indirizzo: http://localhost:4000. Ogni richiesta vuole l'intestazione Authorization: Bearer <token>.

Caselle

curl -H "Authorization: Bearer TOKEN" BASE/v1/mailboxes

Ultime mail (senza il corpo)

Tutte le caselle insieme, oppure una sola con mailbox=. Con unprocessed=1 ricevi solo quelle che questo token non ha ancora segnato come elaborate.

curl -H "Authorization: Bearer TOKEN" "BASE/v1/messages?limit=25"
curl -H "Authorization: Bearer TOKEN" "BASE/v1/messages?mailbox=ID&unprocessed=1"

Una mail completa

Contiene text (ricavato dall'HTML se manca il testo semplice, con la codifica corretta), text_for_agent (lo stesso testo racchiuso tra delimitatori che lo dichiarano dato non fidato) e security.level: high se sembra contenere istruzioni per un'AI.

curl -H "Authorization: Bearer TOKEN" BASE/v1/messages/MAILBOX_ID/UID

Segna come elaborate

Scrive solo nel registro di Leggio, legato al token: la casella non viene toccata.

curl -X POST -H "Authorization: Bearer TOKEN" -H "Content-Type: application/json" \
  -d '{"items":[{"mailbox_id":"ID","uid":123}]}' BASE/v1/processed

Errori

401 token mancante, sbagliato, revocato o scaduto · 429 più di 120 richieste al minuto · 503 Leggio bloccato dopo il riavvio, finché qualcuno non entra nella console · 502 il server della casella non risponde.
